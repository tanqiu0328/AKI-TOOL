# Triage 标签

工程技能使用五类标准 triage 角色，本文件将这些角色映射到仓库 Issue tracker 中的实际标签

| 技能中的标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交由自主代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个标准角色时，应使用表中对应的仓库标签

如需适配仓库已有标签体系，可修改第二列
